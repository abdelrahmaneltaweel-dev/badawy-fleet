## ابدأ من هنا
1. `docs/PROJECT_FRAMEWORK.md`: الحالة، الخطوة التالية، المراحل والمهام (يتحدّث بعد كل مهمة).
2. `docs/vision/Project-Vision-v1.0.0.html`: الرؤية النهائية المجمّدة وسجل القرارات (D-001…D-060).

4. `design/previews/`: معاينات التصميم المعتمدة. `brand/`: الشعار والأيقونات.
