## 1. الثوابت (لا تُكسر)
- **تسليم الملفات كاملة 100% وبأوامر التيرمينال:** ممنوع إعطاء المالك أجزاء كود أو توجيهات تعديل يدوي لأسطر. أي ملف يتغير يُسلّم كاملاً بنسبة 100% مع مساره، ومرفقاً بأوامر الـ Git الجاهزة للنسخ في التيرمينال خطوة بخطوة.
- **مجاني بالكامل ومن غير كارت:** Firebase على Spark فقط (Auth + Firestore + Rules). **ممنوع** Blaze وCloud Functions وStorage وExtensions. GitHub Pages للواجهة، وGitHub Actions كـ Worker، وApps Script جسر Google Sheets والنسخة الاحتياطية فقط.
- **حصص Spark:** حوالي 1 جيجا تخزين، 50 ألف قراءة و20 ألف كتابة في اليوم. أي ميزة لازم تحسب أثرها على القراءات والكتابات. **راجع الحصص الحالية بالبحث قبل الاعتماد** (بتتغير).
- **ريبو عام:** ممنوع أي سر أو بيانات حقيقية (توكنات، عنوان Traccar، إحداثيات المواقع، أرقام تليفونات، أجهزة، بيانات سائقين). الأسرار في GitHub Secrets/Script Properties. القيم الافتراضية في الكود، والبيانات في Firestore.
- **الإعدادات أولًا:** لا ثوابت مدفونة. كل شيء له إدخال في **سجل الإعدادات (Registry)** والمالك يغيّره من المنصة. الحد: خوارزمية تحليل جديدة تمامًا = كود.
- **الاحتساب الأساسي من الـ GPS.** إدخال السائق/الخلاطة/الجراج بيانات مساندة للمطابقة حتى يعتمدها المسؤول.
- **الفترة المقفولة لا تتغير** (لقطة نهائية). التصحيح بعدها = تسوية تُضاف لأول فترة مفتوحة. فتحها بصلاحية وسبب.
- **التصميم:** الاتجاه الهادئ (مرجع `design/previews/Design-System-Preview-v0.3.0-draft.html`)، RTL، أرقام إنجليزية، فاتح/داكن، mobile-first، PWA، قوائم اختيار مخصّصة (مش native)، حركة قصيرة تحترم «تقليل الحركة».
- **الصلاحيات:** Super Admin وحده يعدّل ويقفل ويفتح حاليًا؛ المفاتيح `report.edit`, `period.close`, `period.open`, `adjustment.create/approve`, `import.upload` قابلة للمنح من المنصة.
- **Version control على كل حاجة:** SemVer للكود، `schemaVersion` للبيانات، `rulesVersion` للقواعد، `apiVersion`، إصدارات للوثائق والإعدادات والتخطيطات.
- **الحوار مع المالك:** عامية مصرية بسيطة، إجابة مباشرة، قرار واحد في المرة، ولا تفترض لما تكون الإجابة تأثيرها كبير.

## 5. بروتوكول التحديث بعد كل مهمة
1. تأكد أن **معيار القبول** اتحقق فعليًا (اختبار/تشغيل/لقطة)، مش مجرد كتابة كود.
2. غيّر حالة المهمة (✅ أو ⛔ مع السبب).
3. حدّث **القسم 2**: ما خلص + أي ملفات جديدة + أي قرار جديد (برابط ADR).
4. حدّث **القسم 3** بالخطوة التالية بخطوات دقيقة (مين يعمل إيه، وأي ملف يترفع وأين).
5. حدّث ترويسة الملف: `lastUpdated`، `currentMilestone`، `currentTask`، وزوّد `frameworkVersion`.
6. أضف سطرًا في **القسم 8**.
7. **الملفات كاملة 100% دائماً:** تسليم الملفات المعدلة كاملة مع مساراتها للنسخ والاستبدال المباشر بدون أجزاء مبتورة أو طلب تعديل يدوي.
8. **أوامر Git بالتيرمينال جاهزة للنسخ خطوة بخطوة:** إنشاء الفرع، commit، push، وpull على main بعد الدمج.
9. ما تبدأش المهمة التالية قبل ما المالك يؤكد.

## 6. تعريف الإنجاز (Definition of Done)
- **كود:** يعمل، له اختبارات، مراجَع بـ PR، من غير أسرار، وكل ثابت له إعداد في السجل.
- **واجهة:** تعمل فاتح/داكن/موبايل/ديسكتوب، RTL، أرقام إنجليزية، حركة تحترم «تقليل الحركة»، وتتجنب `<select>` الأصلي.
- **بيانات:** `schemaVersion` + migration + اختبار Rules + حساب أثر القراءات والكتابات.
- **قرار:** ADR + سطر في سجل القرارات.
- **الكل:** CHANGELOG محدّث، والإطار محدّث (القسم 5)، والملفات كاملة 100%.

## 9. مرجع سريع
- **الأدوار:** Super Admin · الإدارة/المالية/HR (عرض وتصدير) · مدير الخلاطة · أمن الجراج (حساب لكل فرد) · السائق · مدير موقع سوهاج.
- **أنواع العربيات:** جرار (نقلات كاملة) · نقل (مشاوير) · ملاكي (مشاوير).
- **النقلة:** خلاطة ← كسارة ← تفريغ ← خلاطة، ويوم التشغيل يبدأ 6 الصباح. الصيانة: وقوف 20 دقيقة داخل الجراج. زيارة المشاوير: وقوف 10 دقائق داخل 250 متر.
- **المطابقة الثلاثية (+ السائق):** GPS ↔ بيان الخلاطة ↔ بيان الجراج ↔ بيان السائق (مساند).
- **المحفظة:** حد ائتماني 50,000 ج.م، إعادة الطلب عند 25,000، اعتماد 24–48 ساعة.
- **Traccar:** سيرفر داخلي، API فقط، تاريخ المسارات سنة.
- **الاحتفاظ:** وقفات وأحداث 12 شهر ثم ملخص شهري · العهدة المرفوضة تُمسح عند الاستبدال والمقبولة 60 يوم · سجل المراجعة 24 شهر · لقطات المقفول دائمة · النسخ الخاصة 3 شهور (كلها من الإعدادات).
