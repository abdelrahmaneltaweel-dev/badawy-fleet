2) المتطلبات (ثابتة حتى الآن)

  • الأسطول: 65 عربية (منهم عربيات نقل بنقلات، والباقي مشاوير). المستخدمين: 15–20 بأدوار.
  • كل حاجة مجانية ومستدامة، من غير كارت ومن غير أي احتمال فاتورة.
  • واجهة على GitHub Pages، وCRUD كامل، وإضافة ميزة لاحقًا تكون سهلة.
  • الريبو عام؛ الأسرار والبيانات مستحيل تتسرب.
  • Google Sheets يفضل نسخة احتياطية لو الموقع وقع.

3) الوضع الحالي (ملخص)

مشروع Apps Script واحد (~5800 سطر): main.gs 2506، Statements 871، Issues 702، Manual edits 536، Errand 524، Dashboard 399، وملفات صغيرة. فيه قواعد شغل مجرّبة (النقلة = خلاطة ← كسارة ← تفريغ ← خلاطة، يوم من 6 الصبح، صيانة 20 دقيقة، زيارة مشاوير 10 دقايق، بصمة التعديلات…) وهي أصل المشروع وتتنقل بنفس الأرقام.

4) المعمارية المقترحة

ليه اتغيّرت عن 0.1.0؟ مع 65 عربية: حصص Apps Script العادي (90 دقيقة triggers/يوم، 20 ألف UrlFetch/يوم، 30 تنفيذ متزامن) هتبقى العنق. وGitHub Pages عام فمينفعش نحط عليه بيانات حية. وTraccar على HTTP فالمتصفح مينفعش يكلمه.
المتصفح (GitHub Pages, ثابت)  ──Auth + قراءة/كتابة بصلاحيات──►  Firebase Spark
                                                                (Firestore + Auth + Rules)
                                                                     ▲
GitHub Actions (cron, Node) ── يسحب من Traccar (HTTP) ── يحسب ── يكتب التغييرات بس

Data layerRepository interface واحد (get/list/create/update/delete). تنفيذ أساسي: Firestore. تنفيذ احتياطي: Sheets. تغيير المخزن = تغيير ملف واحد.
Logic layerدوال نقية بدون شبكة أو تخزين (نقلات، مشاوير، حالة، تعديلات). بتشتغل في Node داخل Actions، وتتختبر بأرقام التحقق (116=19، 118=29…).
API/Worker layerالـ Worker بيكتب snapshots جاهزة؛ الكتابة من الواجهة بتمر عبر قواعد Firestore؛ الإيميل عبر Outbox في Firestore يقرأه Apps Script؛ واتساب بروابط wa.me من الواجهة (بدون API مدفوع).
UI layerSPA (Vite، hash routing، code-splitting) على GitHub Pages + نظام تصميم موحد (tokens) + RTL + فاتح/داكن.

5) الأمان والريبو العام

  • ريبو جديد من الصفر؛ القديم يتأرشف خاص. لو فيه أسرار اتحطت قبل كده: تغيير توكن Traccar.
  • أسرار في GitHub Secrets وScript Properties فقط. عنوان Traccar (حاليًا ظاهر في main.gs) يتنقل لـ Secret.
  • ممنوع في الريبو: إحداثيات المواقع الفعلية، أرقام الأجهزة، أرقام واتساب/إيميلات، توكنات، أي تصدير بيانات.
  • Firestore Rules: رفض الكل كأساس + صلاحية لكل دور؛ تسجيل ذاتي مقفول؛ الإدارة تنشئ المستخدمين.
  • Secret Scanning + Push Protection + pre-commit + .gitignore.

8) قرارات لسه مفتوحة

  1. التخلي عن تقرير النقلات من ملفات Excel؟
  2. محتوى الداشبورد بالظبط، وهل عربيات المشاوير تدخل فيها؟
  3. الأدوار والصلاحيات: إدارة، مهندس، سائق، مدير خلاطة، أمن — وإيه اللي كل دور يشوفه ويعدله؟

  5. الاتجاه البصري: عربي RTL فقط؟ هوية الشركة؟ فاتح/داكن؟
  6. Petro: داخل الموقع أو مستقل؟
  7. قرار التوقيت الصيفي UTC+2 / UTC+3 (مؤجل لـ 24/4/2027).
  8. مصير عربيات النقل بين 10 و65: هل أي عربية جديدة نقل أم مشاوير، ومن يحدد النوع؟
  9. إطار الواجهة: Preact أو Svelte أو Web Components بدون إطار.
