# ADR-031: نافذة مراجعة التغييرات عند الإنهاء

**الحالة:** مقبول (Accepted)

## السياق (Context)
التعديل في Sheets قد يحتوي تغييرات متنوعة تحتاج تصنيفًا قبل التطبيق.

## القرار (Decision)
عند End Editing تُجمَّع التغييرات، ولكل مجموعة: دائم (يُضاف للتخطيط) أو هذه المرة فقط (نسخة خاصة باسم الطلب) أو تجاهل. وللصيغ: عمود محسوب دائم / قيمة ثابتة / هذه المرة. الاختيارات الافتراضية من الإعدادات مع زر «طبّق على الكل».

## النتائج (Consequences)
يطابق معيار قبول T8.4.

## المراجع
الرؤية §2-ط · T8.4
