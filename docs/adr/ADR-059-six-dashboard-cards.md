# ADR-059: بطاقات الداشبورد الست

**الحالة:** مقبول (Accepted)

## السياق (Context)
القسم 2-د يحدد الترتيب المتفق عليه.

## القرار (Decision)
ست بطاقات: حالة الأسطول الآن، مشاكل GPS المفتوحة، استفسارات منتظرة رد، نقلات أمس للجرارات (10) مع المطابقة الثلاثية، مشاوير أمس لعربيات النقل والملاكي، محفظة Petro وطلب العهدة المعلّق. التعديل من الإعدادات (إظهار، ترتيب، حقول، فلاتر).
