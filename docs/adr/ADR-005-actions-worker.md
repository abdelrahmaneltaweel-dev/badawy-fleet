# ADR-005: GitHub Actions كـ Worker بدل Apps Script للشغل التقيل

**الحالة:** مقبول (Accepted)

## السياق (Context)
مع أسطول يضم 65 عربية، تشكل حدود Apps Script العادية (90 دقيقة تشغيل/يوم، 20 ألف استدعاء شبكي) عنق زجاجة حرج. كما أن متصفح الويب لا يمكنه مخاطبة سيرفر Traccar الداخلي مباشرة بسبب قيود CORS وبروتوكول HTTP.

## القرار (Decision)
اعتماد مسارات العمل في GitHub Actions (المجدولة عبر cron والمنفذة ببيئة Node.js) كـ Worker رسمي للعمليات الخلفية الثقيلة: سحب بيانات Traccar، تحليل مسارات الأسطول، وكتابة التغييرات المحسوبة فقط في Firestore.

## نتائج التحقق (Consequences)
- تم إثبات قدرة GitHub Actions على الاتصال بسيرفر Traccar الداخلي وسحب الأجهزة بكود 200 في **Spike S-1 (T1.1)**.
- تم إثبات السرعة الفائقة بتحليل أسطول 65 عربية (65,000 إشارة) في أقل من ثانية واحدة وباستهلاك ذاكرة أقل من 30MB في **Spike S-4 (T1.4)**.
- تم توثيق معمارية `lastSyncTime` لحماية التزامن من تأخيرات مجدول cron.
- تم اعتماد القرار رسمياً ونقله من "مقترح" إلى "مقبول".
