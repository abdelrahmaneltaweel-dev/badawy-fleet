# ADR-015: Config as Data

**الحالة:** مقبول (Accepted)

## السياق (Context)
المطلوب أن يُدار كل شيء من المنصة لا من الكود.

## القرار (Decision)
المستخدمون والصلاحيات والسائقون والعربيات والأنواع وأنواع النقلات وقوائم الاختيارات تُدار من المنصة. الحد: خوارزمية تحليل جديدة تمامًا أو ميزة جديدة = كود.

## النتائج (Consequences)
تتوسع في D-040 (الإعدادات أولًا) وD-044.

## المراجع
الرؤية §2-ج · D-040 · T3.4 · T3.6
