# ADR-002: التخلي عن Looker Studio

**الحالة:** مقبول (Accepted)

## السياق (Context)
عرض التقارير يتم داخل المنصة (D-034) وتعديلها عبر Google Sheets (D-030).

## القرار (Decision)
لا يُستخدم Looker Studio في المنصة.

## النتائج (Consequences)
كل عرض التقارير يُبنى داخل المنصة. الرؤية لا تذكر أسبابًا إضافية للقرار.

## المراجع
الرؤية §7 · D-030 · D-034 · M8

> مستخلص من سجل القرارات في `docs/vision/Project-Vision-v1.0.0.html` (القسم 7). الملف لا يُعدَّل بعد قبوله؛ التغيير بقرار أحدث يلغيه.
