# ADR-027: قوائم الاختيار مكوّن مخصّص (نافذة سفلية على الموبايل)

**الحالة:** مقبول (Accepted)

## السياق (Context)
القائمة الأصلية للمتصفح لا تتماشى مع التصميم المعتمد.

## القرار (Decision)
Select مكوّن مخصّص، ونافذة سفلية (bottom sheet) على الموبايل بدل `<select>`.

## النتائج (Consequences)
ضمن تعريف الإنجاز للواجهة: تجنب `<select>` الأصلي.

## المراجع
الإطار §6 · T2.3
