# ADR-004: Firebase على Spark بدون كارت (Auth + Firestore)

**الحالة:** مقبول (Accepted)

## السياق (Context)
المطلوب منصة مجانية ومستدامة بالكامل بلا كارت وبلا أي احتمال لفاتورة مالية. خطة Firebase Spark المجانية توفر: Auth حتى 50 ألف مستخدم شهرياً، وتخزين Firestore بحوالي 1GB، وحصة يومية 50 ألف قراءة و20 ألف كتابة وحذف.

## القرار (Decision)
اعتماد خطة Firebase Spark المجانية رسمياً كمخزن بيانات مركزي (Firestore + Auth + Rules) بدون إضافة بطاقة دفع، وتصميم معمارية الكود والـ Worker لحساب وعرض البيانات بحيث لا تتجاوز الحصص المجانية اليومية إطلاقاً.

## نتائج التحقق (Consequences)
- تم إثبات صحة وكفاءة القرار عملياً في **Spike S-2 (T1.2)** بنجاح الكتابة والقراءة وحظر الوصول غير المصرح به بكود 403.
- تم إثبات إدارة المستخدمين وصلاحيات الـ Rules بتكلفة صفر قراءات إضافية في **Spike S-6 (T1.3)**.
- تم اعتماد القرار ونقله رسمياً من "مقترح" إلى "مقبول".
