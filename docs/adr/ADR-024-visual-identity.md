# ADR-024: الهوية البصرية: Badawi Group ولوحة الألوان

**الحالة:** مقبول (Accepted)

## السياق (Context)
توجد أصول شعار جاهزة في /brand، والألوان مقيسة منها (تقريبية).

## القرار (Decision)
شعار Badawi Group (مكعب متساوي القياس بدرجات الأزرق + كلمة BADAWI بالكحلي) بنسختين تتبدلان تلقائيًا حسب وضع الجهاز. الألوان: كحلي #0F3A5C، أزرق عميق #1F7391، متوسط/فاتح #5FB4D3 / #8FCFE3. ألوان الحالة منفصلة: Online #2E9E5B، Offline #D64545، واقف/تحذير #E0A100.

## النتائج (Consequences)
الأيقونات والأصول في brand/. تغيير الهوية بطلب صريح فقط.
