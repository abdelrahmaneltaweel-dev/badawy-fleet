# ADR-052: الإطلاق يبدأ بلا عربيات والمسؤول يُضيفها

**الحالة:** مقبول (Accepted)

## السياق (Context)
الشيت الحالي للتجربة فقط.

## القرار (Decision)
عند الإطلاق تبدأ المنصة فارغة ويُدخل المسؤول العربيات والسائقين بنفسه.

## النتائج (Consequences)
مهمة T11.4 مسؤولها المالك.

## المراجع
T11.4 · D-047
