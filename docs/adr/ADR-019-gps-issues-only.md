# ADR-019: المشاكل = مشاكل GPS فقط

**الحالة:** مقبول (Accepted)

## السياق (Context)
المشكلة تُكتشف من حالة الـ GPS (Offline، إشارة مجمدة…).

## القرار (Decision)
تتفتح المشكلة تلقائيًا من منطق الحالة، ومسؤولها Super Admin ويحلها بتليفون للسائق. الحالة: مفتوحة ← تم التواصل ← محلولة مع ملاحظة ووقت.

## النتائج (Consequences)
أي مسألة غير GPS تمر بالاستفسارات (D-017).

## المراجع
الرؤية §2-ب · T6.2
