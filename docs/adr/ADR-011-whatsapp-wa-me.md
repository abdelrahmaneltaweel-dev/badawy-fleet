# ADR-011: واتساب بروابط wa.me فقط (يدوي)

**الحالة:** مقبول (Accepted)

> يلغيه جزئيًا D-054 (الجزء الخاص بالإيميل فقط).

## السياق (Context)
API واتساب الرسمي مدفوع.

## القرار (Decision)
الإشعارات الخارجية بروابط wa.me يضغطها الأدمن يدويًا، والرابط يفتح الاستفسار مباشرة. الاتصال بالسائق عبر tel:.

## النتائج (Consequences)
الإشعارات داخل المنصة بعدّاد معلّق. **جزء الإيميل عبر Outbox أُلغي بقرار D-054**.

الرؤية §2-ج · D-054 · T6.2 · T7.1
