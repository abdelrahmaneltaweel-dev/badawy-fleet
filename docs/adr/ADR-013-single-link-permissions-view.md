# ADR-013: لينك واحد وصفحة واحدة والعرض حسب الصلاحيات

**الحالة:** مقبول (Accepted)

## السياق (Context)
15–20 مستخدمًا بأدوار مختلفة، وكل مستخدم يرى حاجته فقط.

## القرار (Decision)
SPA بلينك واحد: دخول ثم قائمة تُبنى من الصلاحيات. الأمان الفعلي في Firestore Rules.

## النتائج (Consequences)
الواجهة تخفي الشاشات للتنظيم فقط وليس للأمان. اختبارات الـ Rules لازمة لكل دور.

## المراجع
الرؤية §2 و§2-أ و§2-ج · T3.2 · T3.3
