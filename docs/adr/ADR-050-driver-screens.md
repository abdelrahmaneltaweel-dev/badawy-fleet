# ADR-050: شاشات السائق

**الحالة:** مقبول (Accepted)

## السياق (Context)
لكل سائق حساب يرى بياناته ونقلاته فقط.

## القرار (Decision)
ثلاث شاشات: بياناتي، نقلاتي (عرض + إدخال)، استفساراتي (اختيار سبب وشرح مفصل).

## النتائج (Consequences)
تفاصيل الإدخال (المهلة 24 ساعة افتراضًا والحقول الإلزامية) من الإعدادات.

الرؤية §2-ل · T7.5
