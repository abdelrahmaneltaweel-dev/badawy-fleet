# ADR-048: مصدر البيانات: سحب Traccar وبديله رفع Excel الخام

**الحالة:** مقبول (Accepted)

## السياق (Context)
قد يتعطل السحب (S-1) ويلزم بديل.

## القرار (Decision)
المصدر الافتراضي سحب Traccar، وعند تعطله رفع ملفات Excel الخام يدويًا. وسم مصدر كل بيان، ومقارنة عند عودة السحب، ومؤشر صحة السحب.

## النتائج (Consequences)
الرفع يشغّل نفس طبقة logic في المتصفح وتشترط نتائج مطابقة (S-10). البديل في حال فشل S-10: رفع CSV.

الرؤية §2 · S-10 · T1.9 · T5.4 · T5.5
