# ADR-016: Vehicle بمعرّف ثابت وAssignment بتواريخ

**الحالة:** مقبول (Accepted)

## السياق (Context)
الاسم واللوحة والـ GPS والسائق قابلة للتغيير مع الزمن.

## القرار (Decision)
لكل عربية vehicleId ثابت. الإسناد (عربية↔سائق وعربية↔جهاز GPS) بتاريخ بداية ونهاية.

## النتائج (Consequences)
تغيير الإسناد لا يعدّل الماضي، وهو أساس نسب نقلات المرتبات لسائق كل يوم. التعديل بأثر رجعي ممكن بسجل.

## المراجع
الرؤية §2-ب · T3.6
