# ADR-017: Inquiry موحد بخيارات رد قابلة للتعديل

**الحالة:** مقبول (Accepted)

## السياق (Context)
الاستفسارات موجهة لثلاث جهات: السائق ومدير الخلاطة وأمن الجراج.

## القرار (Decision)
كيان استفسار موحد مرتبط بعربية وحدث (وقت+مكان): سؤال ولوكيشن اختياري ورد من قائمة قابلة للتعديل مع ملاحظة. الحالة: معلّق ← تم الرد ← مغلق.

## النتائج (Consequences)
خيارات الرد والمهل والمسؤولون من الإعدادات.
