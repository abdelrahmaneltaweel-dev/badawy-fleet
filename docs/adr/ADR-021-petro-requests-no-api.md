# ADR-021: طلب العهدة (Petro) داخل المنصة بدون API

**الحالة:** مقبول (Accepted)

## السياق (Context)
Petro App له API مدفوع فلن يُربط.

## القرار (Decision)
المنصة تحاكي وحدة الشيت الحالية: تحلل ملفين (تقرير الوقود + كشف الحساب) وتجهّز صفحتين للطباعة (A4، RTL). المبلغ يكتبه الـ Super Admin يدويًا. الدورة: معلّق ← تاني يوم بطاقة «اتوافق عليه؟» ← موافق/مرفوض، والمرفوض يُنشئ طلبًا جديدًا مرتبطًا (محاولة 2، 3…).

## النتائج (Consequences)
الملفات لا تُخزَّن. رصيد المحفظة وتنبيه 25 ألف مشروطان بوجود رصيد جارٍ في كشف الحساب (يتأكد من نموذج فعلي).
