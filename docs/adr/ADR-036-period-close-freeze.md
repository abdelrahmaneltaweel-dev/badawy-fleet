# ADR-036: إغلاق الفترات المعتمدة وتجميد قيمها

**الحالة:** مقبول (Accepted)

## السياق (Context)
المرتبات تحتاج أرقامًا نهائية لا تتغير بتغير الإعدادات أو الأسعار. أصبح القرار متفقًا عليه في 0.4.1.

## القرار (Decision)
زر «إغلاق الفترة» يأخذ لقطة نهائية غير قابلة للتغيير (الأصل + التخطيط + الأعمدة المحسوبة + الأسعار السارية وقتها) مع بصمة وتوقيع (مين، إمتى، لماذا). زر «فتح الفترة» منفصل يطلب سببًا.

## النتائج (Consequences)
بعد الإغلاق: تعديلات الإعدادات والأسعار لا تغيّر الفترة، التصدير والطباعة يحملان «فترة مغلقة»، وEdit in Google Sheets معطّل. إعادة الإغلاق بعد الفتح تُنتج v2 مع بقاء السابق. اللقطات صغيرة (تقديريًا عشرات الكيلوبايتات للشهر) وتُستثنى من التنظيف.
