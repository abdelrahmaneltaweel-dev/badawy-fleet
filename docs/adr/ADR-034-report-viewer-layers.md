# ADR-034: عارض التقارير يطبّق التخطيط المحفوظ بطبقات

**الحالة:** مقبول (Accepted)

## السياق (Context)
نموذج الطبقات من المعاينات: قيم، هيكل، تنسيق.

## القرار (Decision)
العارض يطبّق التخطيط المحفوظ بطبقات مرتبطة بمفاتيح الصف والعمود.

## النتائج (Consequences)
نفس التخطيط يطبَّق على أي فترة.

## المراجع
الرؤية §2-ط · T4.4 · T8.1
