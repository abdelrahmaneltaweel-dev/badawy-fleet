# ADR-032: صلاحية report.edit

**الحالة:** مقبول (Accepted)

## السياق (Context)
التعديل عبر Sheets قوي ويحتاج ضبطًا.

## القرار (Decision)
report.edit للـ Super Admin فقط حاليًا، وقابلة للمنح والسحب من المنصة.

## النتائج (Consequences)
الصلاحية تُمنح وتُسحب من إدارة المستخدمين.

## المراجع
الرؤية §2-ط · T3.3
