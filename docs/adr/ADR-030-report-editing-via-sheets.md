# ADR-030: إلغاء محرر التقارير الداخلي والتعديل عبر Google Sheets مع End Editing

**الحالة:** مقبول (Accepted)

## السياق (Context)
بناء محرر تقارير داخل المنصة مكلف، وGoogle Sheets يوفر أدوات التعديل كاملة.

## القرار (Decision)
زر Edit in Google Sheets يفتح التقرير في Sheets، ثم End Editing في المنصة يعيد التغييرات عبر Apps Script. المنصة هي المرجع والشيت أداة تحرير فقط.

## النتائج (Consequences)
خارج النطاق: الرسوم البيانية وpivot والصور والصيغ المعقدة بين صفوف أو أوراق؛ تظهر في نافذة المراجعة كـ «ستتحول لقيم ثابتة / ستُتجاهل». عمود مفاتيح الصفوف مخفي ومحمي، وجلسة تعديل واحدة نشطة للتقرير الواحد. الرحلة كاملة تحتاج Spike S-9.
