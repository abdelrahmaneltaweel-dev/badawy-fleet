# ADR-026: خط عربي مفتوح الترخيص (IBM Plex Sans Arabic) مستضاف في الريبو

**الحالة:** مقبول (Accepted)

## السياق (Context)
تطبيق الويب والـ PWA يعملان بدون إنترنت (Offline)، وبالتالي يلزم أن يكون الخط الأساسي مدمجاً ومستضافاً ذاتياً داخل الريبو ليعمل فورياً دون طلبات شبكة خارجية لـ Google Fonts.

## القرار (Decision)
اعتماد خط `IBM Plex Sans Arabic` مفتوح الترخيص (OFL) كخط افتراضي للمنصة، واستضافته محلياً داخل الريبو لضمان الأداء والعمل دون إنترنت.

## نتائج التحقق (Consequences)
- تم تدقيق واختيار الخط ضمن القائمة المنتقاة المعتمدة في D-058.
- تم اعتماد القرار ونقله رسمياً من "مقترح" إلى "مقبول".
